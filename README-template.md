## Overview

### The Challenge

Users should be able to:

- Toggle extensions between active and inactive states.
- Filter extensions by All, Active, and Inactive.
- Remove extensions from the list.
- Switch between light and dark themes.
- View a responsive layout on different screen sizes.
- See hover and focus states for interactive elements.

### What I Learned

During this project, I practiced several important JavaScript concepts:

- Fetching data from a JSON file using the Fetch API.
- Using `map()` to generate extension cards dynamically.
- Using `filter()` to display active and inactive extensions.
- Using event listeners to handle user interactions.
- Updating the DOM dynamically.
- Managing application state with JavaScript variables.
- Working with keyboard focus and hover states.

**Challenges I Faced**

One of the challenging parts of this project was implementing the light and dark themes.

- **Theme switching:** I learned how to toggle a CSS class on the body element to switch between light and dark themes and update the theme icon accordingly.
- **Logo colors:** The original logo did not look right in both themes because its text color was different from the background. I created separate light and dark logo versions and used JavaScript to switch between them.
- **Focus states:** I also worked on making keyboard focus outlines visible and consistent across interactive elements.

One important thing I learned was how to use the original index of an item when filtering an array, so that removing or toggling an extension updates the correct item.
